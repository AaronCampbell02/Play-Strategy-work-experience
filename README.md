Play Strategy Work Experience
A Python data visualisation project produced during work experience at Play Stategy, evaluating game/user data and presenting it visually, including an animated bar chart race.

Bar chart race: https://public.flourish.studio/visualisation/19013775/

Project structure
JsonFileReader/ — reads and processes JSON data
csvReaderFiles/ — reads and processes CSV data
graphFolder/ — generates graphs from data
games.csv, users.csv — source data on games and users

Run the scripts in csvReaderFiles/JsonFileReader to process the data, then the scripts in graphFolder to generate the graphs.
